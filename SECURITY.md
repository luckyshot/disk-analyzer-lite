# Security Policy

Disk Analyzer Lite reads file metadata on your computer and can move files to the Trash, so we take bugs that could cause unintended data loss or privilege issues seriously.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub's **Security → Report a vulnerability** on this repository, with steps to reproduce and the affected version. You should get a response within a week.
